# TechSwiftTrix School Portal

A Next.js + TypeScript + Tailwind demo for a modern, enterprise-grade School Management Portal UI inspired by the provided design.

Features included:
- Four role dashboards (Admin, Teacher, Student, Parent)
- Dark navy theme with neon green accents and glassmorphism cards
- Responsive layout with sidebar and topbar
- Mock authentication and role selection
- Sample charts and widgets

Quick start

1. Install dependencies:

```bash
cd "school-portal-demo"
npm install
```

2. Run dev server:

```bash
npm run dev
```

Open http://localhost:3000

Notes
- This is a UI-first demo with mock APIs. Replace mocks with real backend and DB as needed.
